Obsidian 多设备同步配置手册

Obsidian 多设备同步配置手册

Windows、iPhone/iPad、安卓手机/平板双向实时同步同一个 Obsidian Vault，不订阅 Obsidian Sync。

一、最终方案

设备 软件 状态
Windows 电脑 Syncthing 已实测
iPhone / iPad Möbius Sync iPhone 已实测
安卓手机 / 安卓平板 Syncthing-Fork 平板已实测

同步的是整个 Vault（仓库）文件夹（含笔记、图片、PDF、附件、.obsidian），不是 Vault 里的某个子文件夹。

实测状态：Windows + iPhone + 安卓平板 三端互通成功；iPad / 安卓手机按本手册配置，建议先按「十一、三方向测试」验证再放重要笔记。

二、为什么采用 Syncthing

Windows、安卓用 Syncthing 直接同步本地文件夹，iPhone/iPad 用 Möbius Sync 接入，避免长期订阅 Obsidian Sync。

三、先记住两个概念

概念 含义 关键点
Device ID 每台设备的身份 互联 = 双方互知对方的 Device ID
Folder ID 同步文件夹的身份 同一个 Vault 在不同设备上用同一个 Folder ID；路径可以不同

路径不同没关系，Folder ID 一致即可，例如 D:\Obsidian\MyVault 和 内部存储\Obsidian\MyVault。

四、Windows 电脑配置

  1. 安装并打开 Syncthing，进入网页管理界面。
  2. 在资源管理器里找到整个 Vault 文件夹（不是 Vault 内的子文件夹），确认里面有 .md、图片、PDF 等。
  3. 点击 Add Folder / 添加文件夹：
字段 填什么
Folder Label MyVault
Folder ID 用自动生成的即可，先复制保存——这是整条同步链的钥匙，后面每台设备都要填同一个，不能各自生成
Folder Path 实际 Vault 文件夹，如 D:\Obsidian\MyVault
Folder Type Send & Receive

为什么 Send & Receive： 所有设备都要改 Vault，双向同步（电脑↔移动端）。

新设备第一次接入顺序： Windows 先同步到 Up to Date → 新设备用「全新（空）Vault」接入、让 Windows 内容完整拉过来 → 两端都 Up to Date 再正常使用 → 新设备有旧内容先备份。

五、苹果移动端配置（iPhone / iPad）

  1. 安装 Möbius Sync。
  2. 互联：苹果端复制自己的 Device ID → Windows 里 Add Remote Device 填入；再从苹果端添加 Windows 的 Device ID。
  3. 注意：互联 ≠ 文件夹共享。互联解决”能不能通信”，之后还要指定”允许同步哪个文件夹”。

六、苹果端 Vault 怎么放

方案 A（免费）：只能同步 Möbius Sync 的 sandbox 文件夹（有容量限制）。

  1. 文件 App → 我的 iPhone/iPad → 找到 Möbius Sync 文件夹；
  2. 把整个 Vault 移动/复制进去（我的iPhone/Möbius Sync/MyVault）；
  3. Obsidian → 打开已有仓库 → 选这个 MyVault。

关键：Möbius Sync 同步的文件夹 = Obsidian 打开的 Vault，不是”Vault 里再放一个 Möbius Sync 文件夹”。

方案 B（付费）：用 Pick External Folder 直接选择原有 Vault 文件夹即可。测试用免费版，长期用付费版更方便。

七、苹果端加入 Vault 同步

  1. 点击 Add Folder；
  2. 免费版选 Möbius Sync 文件夹里的 MyVault；付费版用 Pick External Folder 直选；
  3. 设置：
    • Folder ID = Windows 的 Folder ID（手动照抄，别自动生成）；
    • Folder Type = Send & Receive；
  4. 确认 Windows 和苹果两端都出现这个 Folder，等待同步。

八、安卓手机 / 平板配置

  1. 安装 Syncthing-Fork；
  2. 互联：安卓复制 Device ID → Windows 添加；安卓再添加 Windows 的 Device ID，直到显示 Connected；
  3. 打开 Obsidian，Vault 放到 Device Storage / 设备存储（别用 App Storage），Syncthing 才能访问；
  4. Windows：MyVault → Edit → Sharing 勾选安卓并保存；
  5. 安卓接受共享请求，选保存位置（如 内部存储/Obsidian/MyVault）；
  6. 检查 Folder ID 与 Windows 一致（不一致就手动改），Folder Type 为 Send & Receive。

九、多设备最终结构

采用两两互联，无需中转设备，例如 Windows↔iPhone、iPhone↔iPad、iPhone↔安卓平板等。目标是所有设备共同参与同一个 Vault 的同步。

十、配置完成后的检查

每台设备确认：

检查项 应为
设备状态 Connected
文件夹 MyVault
Folder ID 所有设备一致
Folder Type Send & Receive
Folder Path 指向各设备自己的 Vault
同步状态 Up to Date

十一、三方向测试

别拿重要笔记测，分别新建测试文件：

方向 新建文件 到哪确认
Windows → 移动端 SyncTest-Windows.md iPhone/iPad、安卓
iPhone → 其他 SyncTest-iOS.md Windows、安卓
安卓 → 其他 SyncTest-Android.md Windows、iPhone/iPad

三个方向全部成功 = 同步配置完成。

十二、日常使用

不用手动上传/下载，修改后自动同步；当时离线的设备下次上线会自动补同步。

十三、三个最重要的使用注意

  1. 不要同时编辑同一个文件：电脑改 A.md 时手机别一起改，易冲突；等一台同步完再换下一台。
  2. 不要随便改 Vault 名称/文件夹名称：名称变了但 Syncthing 仍指向旧路径 → Folder Path missing → Folder 变 Stopped。必须改名时，改完到 Syncthing → Edit → 更新 Folder Path；改名 ≠ 重建 Folder，Folder ID 别乱改。
  3. 真冲突了怎么办：冲突时会生成副本，如 A - 电脑名1.sync-conflict-20260923-123456.md。处理：对比两份 → 留正确较新的一份 → 改回正常文件名（如 A.md）→ 删掉另一份和 .sync-conflict- 副本。

十四、出问题按这个顺序查

  1. Device 是否 Connected
  2. Folder 是否 Stopped
  3. 有无 Error
  4. Folder Path 是否真实存在
  5. Folder ID 是否一致
  6. Folder Type 是否 Send & Receive
  7. 文件夹是否共享给了对应设备

最常见 Folder Path missing：找到实际 Vault 文件夹 → 复制路径 → Syncthing → Edit → 修改 Folder Path。

十五、同步 ≠ 备份

电脑删除会同步删到其他设备（误删=全部没有）。重要资料务必另外备份。
