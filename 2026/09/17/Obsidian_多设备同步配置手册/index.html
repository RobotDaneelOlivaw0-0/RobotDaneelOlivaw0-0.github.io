二、为什么采用 Syncthing 这套方案

【选择原因】

设备包括 Windows、iPhone / iPad、安卓手机 / 安卓平板，同时不想长期订阅 Obsidian Sync。

Syncthing 的特点是直接同步本地文件夹；iPhone / iPad 则通过 Möbius Sync 接入，Android 使用 Syncthing-Fork。

三、配置前先记住两个概念

1. Device ID = 设备身份

每台设备都有自己的 Device ID。

设备互联就是让两个设备互相知道对方的 Device ID。

2. Folder ID = 同步文件夹身份

要同步的 Vault 会在 Syncthing 中对应一个 Folder ID。

同一个 Vault 在不同设备上使用同一个 Folder ID。

但是不同设备的实际保存路径可以不同。

例如：

路径不同没关系，Folder ID 相同即可。

五、苹果移动端配置

适用于 iPhone、iPad。

① 安装 Möbius Sync

安装 Möbius Sync。

② Windows 与苹果移动端建立设备互联

在苹果设备中找到 Device ID，复制。

Windows Syncthing：

Add Remote Device / 添加远程设备

输入苹果设备的 Device ID，保存。

然后在苹果设备中添加 Windows 的 Device ID。

【为什么要做这一步】

设备互联 ≠ 文件夹共享。

设备互联解决：

“这两个设备能不能互相通信？”

之后还要指定：

“允许它们同步哪个文件夹？”
